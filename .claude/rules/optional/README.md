# optional/ ルール

このディレクトリのルールはプロジェクトに応じて選択的に使用する。必要なファイルを `rules/` にコピーして適用する。

## ファイル一覧

| ファイル | 説明 |
|---------|------|
| `operation-log.md` | データベース変更操作時の操作ログ記録ルール |
| `soft-delete-display.md` | ソフトデリートされたレコードの表示ルール（バックエンド + フロントエンド） |
| `inertia-toast.md` | Inertia.js フラッシュメッセージによるトースト通知ルール |
| `workstation-port.md` | 共有ワークステーション環境での Docker ポート設定ルール |
