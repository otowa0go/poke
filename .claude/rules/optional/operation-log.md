# 操作ログ

## 原則

**データベースの中身を変更する操作（作成・更新・削除・複製等）を実装する際は、必ず操作ログを記録すること。**

操作ログには以下の情報を含めること：

- **操作種別**: 作成（create）、更新（update）、削除（delete）、複製（duplicate）など
- **対象モデル**: 操作対象のモデル名またはテーブル名
- **対象ID**: 操作対象のレコードID
- **操作内容の説明**: 人間が読める形式の操作説明
- **変更内容**: 変更前後の値（任意、更新操作で有用）

## 実装方法

具体的な実装方法（サービスクラス、ミドルウェア、イベント等）はプロジェクトごとに定義してください。

以下の点を考慮して設計すること：

- 操作カテゴリ（商品、注文、マスタ、ユーザー等）ごとに分類できる構造
- 操作ユーザーの自動記録（認証情報からの取得）
- トランザクション内での記録（操作とログの整合性を保つ）
